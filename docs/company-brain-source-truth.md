# Afrishore Company Brain — Source of Truth

**This is Layer 3 of the Afrishore Company Brain** (capture → retrieval → **source truth** →
permissions → feedback). Its job is to answer one question for any agent or person drafting
on Afrishore's behalf: *when two facts conflict, which one wins — and what may go in public?*

A services company challenging incumbents (GAC, Inchcape, Manica/OLS, Rennies) loses more from
**one overclaim on a tender** than from a hundred missed keywords. This file exists so no agent
becomes a "confident liar with better formatting." If a fact isn't in Tier 1 or Tier 2 and
cleared for public use, **don't state it publicly.**

## How to use this file

Every fact carries a **tier**. The tier decides where it may appear:

| Tier | Meaning | May appear in |
|------|---------|---------------|
| **T1 — Live truth** | Confirmed, current, must always be accurate | Anything, including tenders & public web |
| **T2 — Quotable proof** | Real projects/facts, *verify from records before public use* | Public content **after** verification tick |
| **T3 — Inform, don't quote** | Strategy & internal reasoning | Internal only — shapes work, never published |
| **T4 — Never public** | Guardrails: things that are NOT true or NOT ours to share | Used only to *prevent* a claim |

**Conflict rule:** newest **confirmed** record wins over older; a written cert/registration wins
over memory; this file wins over an agent's general knowledge. When unsure → treat as T4 (withhold)
and flag for a human, don't guess.

Status marks: ✅ confirmed · 🔍 verify before public use · ⬜ unknown / to populate
